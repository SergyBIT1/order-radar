# order-radar — монитор свежих заказов FL.ru в Telegram

Ловит новые заказы с FL.ru по ключевым словам и присылает уведомление
в Telegram в первые минуты после публикации — пока на заказе 0 откликов.

## Что умеет

- Читает официальную RSS-ленту заказов FL.ru
- Фильтрует по ключевым словам из `keywords.txt` (подстроки и regex)
- Различает 🟢 бесплатные отклики («для всех») и 💰 платные
- Защита от дублей через SQLite (`radar.db`)
- Без внешних зависимостей: только стандартная библиотека Python 3

## Запуск

```bash
# Тест в консоль (без Telegram):
python3 radar.py once

# Постоянная работа (каждые 5 минут):
TG_BOT_TOKEN=токен TG_CHAT_ID=твой_chat_id python3 radar.py loop 300
```

Как получить Telegram-настройки:
1. `TG_BOT_TOKEN` — создать бота у @BotFather (`/newbot`)
2. `TG_CHAT_ID` — написать своему боту любое сообщение, затем открыть
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id`

## Автозапуск (macOS, cron)

```
*/5 * * * * cd /путь/к/order-radar && TG_BOT_TOKEN=... TG_CHAT_ID=... /usr/bin/python3 radar.py once >> radar.log 2>&1
```

## Первый запуск

Первый проход молча наполняет базу (чтобы не прислать 50 старых заказов)
и показывает в консоли текущие совпадения. Уведомления начинаются
со второго прохода — только о новых заказах.

## Настройка под себя

Ключевые слова — в `keywords.txt`: одна строка = слово/фраза,
строка `re:...` = регулярное выражение, `#` = комментарий.
